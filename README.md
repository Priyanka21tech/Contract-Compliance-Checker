# 🔍 Contract Compliance Checker (Agentforce)

## 🚀 Overview
An AI-powered contract compliance system built using Salesforce Agentforce that automatically analyzes uploaded contract PDFs and validates them against predefined master agreements.

## 🧠 Key Features
- Extracts full text from uploaded PDF documents
- Compares contract clauses with master compliance documents
- Identifies financial and security risks
- Generates structured compliance reports using Agentforce
- Automates manual contract review process

## ⚙️ Tech Stack
- Salesforce Agentforce
- Salesforce Flows
- Prompt Engineering
- LWC component creation using VS
- File Handling in Salesforce

## 🔄 Workflow
1. User uploads a contract PDF to Salesforce
2. Agent extracts document content
3. Matches clauses with master documents stored in data library
4. Evaluates compliance rules (financial & security)
5. Flags risks and generates structured output

## 🏗 Architecture Highlights
- Flow-driven orchestration
- Agent-based reasoning using prompts
- Document comparison logic
- Output rendered via Agent instructions

## 💡 Business Impact
- Reduces manual contract review effort
- Improves compliance accuracy
- Enables faster risk identification
